# 图文内容增长 Agent 企业员工使用教程

> 适用读者：企业内容运营、审核人员和日常使用员工
>
> 当前版本：1.4.6（内容生命周期与二做闭环版）
>
> 核验日期：2026-08-11

## 1. 你要先知道的事

这个工具把“找爆款、分析、人工选款、一做、图片生成、人工发布、数据观察、二做”串成一条工作流。它不会替你绕过平台登录、验证码或发布确认；需要你确认的地方会停下来。

当前可实际使用的主链路是小红书公开图文。抖音有抓取、分析和一做适配，但真人页面与 24 小时压力验收尚未完成，抖音发布后数据分析未接入；在验收完成前不要打开抖音自动模式。

## 2. 第一次启动

1. 打开解压后的 `成品` 文件夹。
2. 双击 `启动图文爆款Agent.bat`。不要把 BAT 单独复制到桌面，也不要从两个不同版本同时启动。
3. 如果出现 Chrome 路径检查，选择本机真实的 `chrome.exe`。常见位置包括 Chrome 安装目录或用户目录；程序会记住选择。
4. 工作台打开后，确认页面顶部服务状态正常；也可以访问 `http://127.0.0.1:17851/health`。
5. 关闭时双击 `关闭图文爆款Agent.bat`。只关网页或 EXE 窗口不会关闭后台。

## 3. 配置平台登录

1. 打开“接入与设置”。
2. 在小红书部分填写关键词，保留或删除默认关键词均可。
3. 点击“打开登录窗口”，在专用 Chrome 中人工登录小红书。
4. 关闭登录页面前不要退出账号。回到工作台点击“检查登录状态”。
5. 先运行一次“测试抓取”，确认能读到公开图文，再开始正式抓取。

抖音登录步骤相同，但必须先完成企业自己的真人小样本验收；未验收时保持抖音开关关闭。遇到验证码请人工处理或暂停，不要连续点击。

## 4. 配置三类模型

模型分为文本、视觉、生图三类，分别保存、测试和激活：

- **文本模型**：用于标题/正文分析、结构复审、策划和提示词起草。
- **视觉模型**：用于逐张图片拆解；分析阶段还需要文本模型综合复审。
- **生图模型**：只在人工确认一做提示词后调用。

每类模型都填写供应商提供的 Base URL、模型名和 Key，然后依次点击“保存”“测试连接”“激活”。只保存但未测试成功的档案不能作为当前档案。供应商切换时新建或修改连接档案即可，不要改代码。

如果测试出现 400、500 或 502，先确认供应商文档中的协议、模型名、资源额度和 Base URL；不要把 `/v1/chat/completions`、`/responses`、`/images/generations` 和 `/images/edits` 混用。Key 不要发给同事或写到截图里。

## 5. 建立企业素材库

1. 打开“企业素材库”，点击新建资料库。
2. 名称是唯一必填项；品牌、产品、事实、卖点、红线和视觉要求可后补。
3. 保存后，可在原资料库卡片中点击“+ 添加图片”追加图片，不会覆盖原库，也不需要重新填写文字资料。
4. 图片名称和说明可以后补；没有图片说明时，图片只会归档，不会被 AI 自动当成生产约束。
5. 需要迁移时，在资料库卡片点击导出，得到文字资料、图片原文件、图片说明和 JSON 清单组成的快照包。
6. 一做时可以选择自动使用、必须使用企业原图或不使用企业图。

不要把企业 Key、Cookie 或正式素材放进源码目录；运行数据默认保存在当前 Windows 用户的 `%APPDATA%\ContentOpsAgentV2`。

## 6. 抓取和分析

### 手动运行

1. 在总控台确认人工总控已开启，或直接点击“开始抓取”。明确点击人工任务会自动开启人工总控，但不会擅自打开 24 小时开关。
2. 点击“运行抓取”或“运行完整工作流”。
3. 系统先通过专用 Chrome 搜索关键词，再读取详情，过滤视频、无图、低相关、低互动和残缺内容。
4. 配置文本和视觉模型后，系统执行“文本初析 → 视觉逐图拆解 → 文本综合复审”。
5. 结果进入“候选与选款”。低质量内容被过滤并不会进入候选池。

### 人工选款

在“候选与选款”查看标题、正文、图片和分析信号。选择要借鉴的候选，忽略无关候选；完成一做后它会从候选页退出，成品会进入“已生产内容库”。

## 7. 一做和图片生成

1. 在候选页选中内容后，进入“图文生产”或对应的一做工作台，点击“开始策划”。
2. 文本模型会结合爆款参考、当前企业素材库和已选择的文字规则，起草标题、正文、标签和逐页图片提示词。
3. 人工逐项检查并修改标题、正文、标签和每页提示词。提示词里是否带文字、使用哪种语言、什么风格、实景还是动画，都由你明确写入或删除；系统不会偷偷追加创作要求。
4. 选择图片参考策略：
   - **自动使用**：条件满足时附带企业参考图。
   - **必须使用企业原图**：没有可用企业图或当前档案不支持参考图时直接阻止。
   - **不使用企业图**：只把工作台提示词发给生图模型。
5. 确认后再点击生成图片。兔子等支持 generations JSON 的供应商使用参考图 JSON 模式；标准编辑接口使用 Edits multipart。系统能够处理返回的 base64 或 URL，并按真实格式保存。
6. 生成期间不要重复点击。重新打开页面会显示已有任务；失败页可单独重试，已完成页不会被重复生成。
7. 人工审核通过后，可删除或新增图片页、调整顺序、编辑文案，然后导出到指定文件夹。导出包含图片、标题、正文、标签、逐页提示词和来源记录。

## 8. 人工发布和二次分析

### 发布

系统不自动替企业账号发布。导出一做成品后，人工在小红书发布，并保留实际发布时间和最终链接。

### 登记和读取数据

1. 打开“分析与二做”。
2. 登记小红书笔记链接和实际发布时间；手填曝光、点赞等数据不是必填项。
3. 点击“检查后台登录”，在专用 Chrome 登录企业自己的小红书创作服务平台。
4. 系统读取可见的“数据看板 → 内容分析 → 笔记数据”表，不逆向后台 API。
5. 发布后立即尝试初始快照，并按设置的 2、24、72 小时节点采样曝光、观看、封面点击率、赞评藏、涨粉、分享、人均观看时长和弹幕等数据。
6. 每条笔记可以单独点击“立即读取本条数据”。若笔记尚未入表、标题被截断或同标题有歧义，系统会明确显示未匹配，不会把数据写到别的笔记。

只有真实创作者后台观察节点才会触发二做建议；人工补录是兜底数据，不会直接触发二做。

## 9. 二做

当“分析与二做”给出阶段结论并允许扩展时，人工确认要做的数量和方向。系统用原成品的 `parentVariantId` 建立二做关系，仍然经过文字策划、人工编辑、生图确认和审核，不会因为一次数据刷新就自动批量发布。

## 10. 24 小时自动运行

1. 先完成一次手动小样本：登录、抓取、模型测试、企业素材库、一做和导出都跑通。
2. 在设置中打开“24 小时自动运行”，设置上午和下午时段、抓取数量、并发、预算和二做数量。
3. 回到总控台，点击人工总控“启动”。自动任务只在总控开启且自动开关开启时运行。
4. 自动链路遇到选款、生图确认、发布或二做会停在人工闸门，不会自动消耗预算或发布。
5. 任何时候点击“立即停止”。如果有网页或模型请求尚未返回，界面会显示“正在停止”；等状态完全收敛后再启动。

抖音真人页面和压力验收完成前不要把抖音加入 24 小时运行。

## 11. 关闭和故障处理

### 正常关闭

双击 `关闭图文爆款Agent.bat`。它会关闭属于本产品的 watchdog、launcher、Node backend 和专用 Chrome，不会关闭普通 Chrome 或其他 Node 服务。

### 常见问题

- **启动说找不到路径**：确认 BAT 和 `runtime\node.exe`、`server.cjs` 在同一完整包或最多两层外壳内；不要从多个版本的外层目录启动。
- **页面打不开**：先关闭，再重新双击启动 BAT；访问 `/health` 确认 17851 的 root 是否是当前成品。
- **小红书抓取超时**：先检查登录状态。采集器会自动恢复最多 2 次；不要反复点击同一任务。
- **视觉分析阻塞**：确认视觉档案已测试并激活，图片 URL 可被供应商读取，额度足够；失败会保留原因，可在配置修好后继续受阻任务。
- **生图反复生成**：查看任务状态，已有任务受防重保护；不要连续点击。失败页可单页重试。
- **后台数据没有匹配**：确认链接、发布时间、创作者后台登录和笔记是否已进入数据表，等待下一采样节点。
- **设置保存后看似没变化**：确保字段已保存；离开页面前如有未保存修改会提示。

## 12. 安全与合规

- 只抓取允许读取的公开图文和企业自有后台。
- 不绕过验证码、登录保护、访问限制或平台服务条款。
- 不把账号 Cookie、API Key、企业素材上传到群聊或公共仓库。
- 导出文件夹可能包含企业机密，按企业权限保存和传输。
- 看到平台页面结构变化、异常验证或无法匹配时，暂停任务并记录错误，不要盲目增加并发。
