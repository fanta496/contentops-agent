# 图文内容增长 Agent

当前版本：1.4.6

整理日期：2026-08-13

这是一个由个人开发者维护的 Windows 本地图文内容工作流。它把公开图文采集、低质量过滤、文本与视觉分析、人工选题、内容制作、生图、人工审核、导出和发布后观察串成可暂停、可复查的流程。

项目以个人开发和本地使用为定位，不要求披露维护者实名，也不包含任何账号、密钥、私有资料或第三方登录态。

## 本地运行

需要 Windows 与 Node.js 18 或更高版本。模型 Key 和飞书 Webhook 由当前 Windows 用户的 DPAPI 加密保存；因此该开源版本不支持 macOS 或 Linux：

```powershell
node server.cjs
```

打开 `http://127.0.0.1:17851/`。

实际采集需要本机 Chrome、由使用者手动完成的平台登录、模型供应商 Key，以及自己拥有或有权使用的参考资料。程序不会绕过验证码、登录保护或平台规则。

可选的 Windows 运行包不写入 Git 历史。若维护者发布了附件，请从 GitHub Releases 下载，并按随附 SHA-256 清单核验。

## 当前边界

- 小红书公开图文抓取、文本/视觉分析、一做、生图和创作后台数据观察已有代码闭环。
- 抖音已实现公开图文采集、分析和一做适配；真人页面、24 小时压力验收与发布后二次分析尚未完成，完成前请保持自动模式关闭。
- 只读取允许访问的公开页面和使用者自行登录的创作后台，不绕过验证机制。
- 采集浏览器通过私有进程管道控制，不开放可被端口扫描或 HTTP 调试接口接入的 Chrome 调试 TCP 端口。

## 开发

核心实现位于根目录、`ai/`、`collector/` 和 `launcher/`。运行前请自行检查源码，且不要将真实 Key、Cookie、状态文件、参考图片或 Chrome profile 提交到仓库。
