# 图文内容增长 Agent

当前版本：2.0.0

整理日期：2026-08-13（2.0.0 更新于 2026-10-22）

这是一个由个人开发者维护的 Windows 本地图文内容工作流。它把公开图文采集、低质量过滤、文本与视觉分析、人工选题、内容制作、生图、人工审核、导出和发布后观察串成可暂停、可复查的流程。

项目以个人开发和本地使用为定位，不要求披露维护者实名，也不包含任何账号、密钥、私有资料或第三方登录态。

## 本地运行

需要 Windows 与 Node.js 18 或更高版本，以及任意 **Chromium 内核浏览器**（Chrome 或 Edge 都可以）。
模型 Key 和飞书 Webhook 由当前 Windows 用户的 DPAPI 加密保存；因此该开源版本不支持 macOS 或 Linux：

```powershell
npm start          # 等价于 node server.cjs
```

打开 `http://127.0.0.1:17851/`。

首次采集前需要在界面里打开专用浏览器并**人工完成一次登录**，登录态会保存在独立配置目录中。

实际采集需要本机 Chrome 或 Edge、由使用者手动完成的平台登录、模型供应商 Key，以及自己拥有或有权使用的参考资料。程序不会绕过验证码、登录保护或平台规则。

> **实验性能力（beta）**：预算/计费（`lib/budget.cjs`、`lib/retry.cjs` 与连接测试的收费路径）仍在收紧中，默认建议先用小额度试跑，并把每日预算当作"预警线"而不是硬性财务上限。

预算相关：本项目提供的是**本地预算保护与预警**（按配置价格估算、并发预留、失败保守入账），不宣称是供应商侧的绝对支出上限——真实扣费以供应商账单为准。

采集节奏是刻意放慢的：搜索后按"内容是否新增"等待、操作间隔按对数正态分布采样，
不使用固定 sleep 高频拉取。这类参数可以在设置里调，但调快只会提高被平台要求验证的概率。

可选的 Windows 运行包不写入 Git 历史。若维护者发布了附件，请从 GitHub Releases 下载，并按随附 SHA-256 清单核验。

## 当前边界

- 小红书公开图文抓取、文本/视觉分析、一做、生图和创作后台数据观察已有代码闭环。
- 抖音为**实验性功能，默认关闭**：登录/搜索/详情/入库链路可用，但页面自动化路线受平台限流影响（连续搜索会返回空壳页），
  且搜索结果的图文占比很低；下一版计划改走接口路线。开启前请手动单次运行验证。
- 只读取允许访问的公开页面和使用者自行登录的创作后台，不绕过验证机制。
- 采集浏览器通过私有进程管道控制，不开放可被端口扫描或 HTTP 调试接口接入的浏览器调试 TCP 端口。

## 开发

模块划分、请求链路、加接口/加平台的改动清单见 [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)；版本变更见 [`CHANGELOG.md`](CHANGELOG.md)。

```powershell
npm test          # 全量检查：语法 / 安全回归 / 采集器契约 / 浏览器路径 / 接口快照 / 升级兼容 / 隐私 / 静态契约 / 启动退出码 / 离线自检

```

核心实现位于根目录、`lib/`、`ai/`、`collector/` 和 `launcher/`。运行前请自行检查源码，且不要将真实 Key、Cookie、状态文件、参考图片或浏览器 profile 提交到仓库。
